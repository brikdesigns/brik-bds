One ladder orders every layer that has to outrank another. Use a `--bds-z-*` token in `z-index` instead of a raw number, so the order is read from the name rather than guessed from `20` against `9`.

```css
.app-top-bar {
  position: sticky;
  top: 0;
  z-index: var(--bds-z-shell);
}
```

## Stacking-order table

Listed from the bottom of the stack to the top. A higher row always paints over a lower one.

| Token | Value | Layer | Used by |
|---|---|---|---|
| `--bds-z-sticky` | 10 | Sticky in-flow chrome, such as the sidebar | `SidebarNavigation`, `SubNavigation` |
| `--bds-z-page-header` | 20 | Sticky page header | `PageHeader` |
| `--bds-z-shell` | 30 | App shell top bar — above the page header | none yet (portal top bar uses 9) |
| `--bds-z-dropdown` | 100 | Menus, popovers, date pickers, address and filter lists | `Menu`, `Popover`, `TopNavigation`, `FilterButton`, `AddressInput`, `DatePicker`, `AddableEntryList`, `AddableTagList` |
| `--bds-z-sheet-backdrop` | 900 | Sheet scrim | `Sheet` |
| `--bds-z-sheet` | 901 | Sheet panel | `Sheet` |
| `--bds-z-modal` | 1000 | Modal | `Modal` |
| `--bds-z-dialog` | 1100 | Dialog — over a modal it was opened from | `Dialog` |
| `--bds-z-tooltip` | 1200 | Tooltip — over every surface it can point at | `Tooltip` |
| `--bds-z-max` | 9999 | Developer tooling that must never be covered | `TaskConsole` |

<Callout type="info">
  Every layer value in component CSS reads from this table, so the table is the single source. A raw `z-index` of 0–4 is fine only for stacking inside one component, such as a decorative layer behind content. Moving onto the scale changed three values: `Tooltip` went from 1000 to 1200, so a tooltip inside a modal is no longer tied with it; `DatePicker` went from 50 to 100 and `AddableEntryList` / `AddableTagList` from 200 to 100, so every dropdown sits on one rung.
</Callout>

## Order rules

- The **shell** sits above the **page header**, so a sticky header scrolling under the top bar never paints over it.
- Both sit below **dropdown**, **sheet**, **modal**, **dialog** and **tooltip**, so an open overlay covers the shell.
- Don't add `calc(var(--bds-z-modal) + 1)`. If a layer needs its own rung, it needs a token added to the scale.
