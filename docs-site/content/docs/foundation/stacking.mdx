One ladder orders every layer that has to outrank another. Use a `--bds-z-*` token in `z-index` instead of a raw number, so the order is read from the name rather than guessed from `20` against `9`.

```css
.app-top-bar {
  position: sticky;
  top: 0;
  z-index: var(--bds-z-shell);
}
```

## Stacking-order table

Listed from the bottom of the stack to the top. A higher row always paints over a lower one.

| Token | Value | Layer | Today's raw value it maps to |
|---|---|---|---|
| `--bds-z-sticky` | 10 | Sticky in-flow chrome, such as the sidebar | `SidebarNavigation` 10 |
| `--bds-z-page-header` | 20 | Sticky page header | `PageHeader` 20 |
| `--bds-z-shell` | 30 | App shell top bar — above the page header | none yet (portal top bar uses 9) |
| `--bds-z-dropdown` | 100 | Menus, popovers, date pickers, address and filter lists | `Menu`, `Popover`, `TopNavigation`, `FilterButton`, `AddressInput` 100; `DatePicker` 50; `AddableEntryList`, `AddableTagList` 200 |
| `--bds-z-sheet-backdrop` | 900 | Sheet scrim | `Sheet` 900 |
| `--bds-z-sheet` | 901 | Sheet panel | `Sheet` 901 |
| `--bds-z-modal` | 1000 | Modal | `Modal` 1000 |
| `--bds-z-dialog` | 1100 | Dialog — over a modal it was opened from | `Dialog` 1100 |
| `--bds-z-tooltip` | 1200 | Tooltip — over every surface it can point at | `Tooltip` 1000 |
| `--bds-z-max` | 9999 | Developer tooling that must never be covered | `TaskConsole` 9999 |

<Callout type="info">
  Component CSS still carries the raw values in the last column. Moving each component onto this scale is tracked separately, so until then the tokens are for new code and for consumers. `Modal` and `Tooltip` both use 1000 today and tie; the scale puts the tooltip above the modal, so a tooltip inside a modal is never hidden by it.
</Callout>

## Order rules

- The **shell** sits above the **page header**, so a sticky header scrolling under the top bar never paints over it.
- Both sit below **dropdown**, **sheet**, **modal**, **dialog** and **tooltip**, so an open overlay covers the shell.
- Don't add `calc(var(--bds-z-modal) + 1)`. If a layer needs its own rung, it needs a token added to the scale.
