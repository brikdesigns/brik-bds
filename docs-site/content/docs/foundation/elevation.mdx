**Elevation** is the Figma collection that governs depth (modes `flat` / `subtle` / `lifted` / `dramatic`). It ships two Primitive groups — `box-shadow` and `blur-radius` — that compose into the ready-to-use semantic `--shadow-*` values components reference. The CSS variable prefix stays `--shadow-*` / `--box-shadow-*`; the *collection and this page* carry Figma's name, Elevation.

<Callout type="warn">
  **Use composed semantic shadows in component CSS** — `--shadow-sm`, `--shadow-md`, `--shadow-lg`, `--shadow-xl`. Never compose raw blur and spread values yourself; the semantic tokens are tuned together for consistent perceived elevation.
</Callout>

## From Figma Elevation to shadow tokens

A Figma variable holds a single dimension, so the Elevation collection's `box-shadow` group exports as `--box-shadow-sm/md/lg/xl` carrying only a **blur value** (e.g. `2px`) — not a usable `box-shadow` shorthand. [`tokens/gap-fills.css`](https://github.com/brikdesigns/brik-bds/blob/main/tokens/gap-fills.css) closes the gap: it defines the real multi-part `--shadow-*` shorthands, then re-aliases `--box-shadow-* → var(--shadow-*)` so either name resolves to the correct value.

| Layer | Names | Where |
|---|---|---|
| Figma collection | `Elevation` → groups `box-shadow`, `blur-radius` | `design-tokens/tokens-studio.json` |
| Style Dictionary output | `--box-shadow-*` (single blur), `--blur-radius-*`, `--shadow-blur/offset/spread-*` | `tokens/figma-tokens.css` |
| Composed semantic (what you use) | `--shadow-sm/md/lg/xl`, `--shadow-overlay` | `tokens/gap-fills.css` |

<Callout type="info">
  **Both `--shadow-*` and `--box-shadow-*` ship and resolve identically.** Component CSS uses each today. Prefer `--shadow-*` in new work; `--box-shadow-*` is the Figma-emitted alias kept alive by the bridge above (a load-bearing override, not drift).
</Callout>

## Composed shadow tokens

Ready-to-use `box-shadow` values defined in `tokens/gap-fills.css`. These are what components reference.

| Token | CSS Variable | Value | Use case |
|---|---|---|---|
| Small | `--shadow-sm` | `0px 2px 4px 0px rgba(0,0,0,0.06)` | Subtle cards, inputs |
| Medium | `--shadow-md` | `0px 4px 12px 0px rgba(0,0,0,0.12)` | Cards, panels |
| Large | `--shadow-lg` | `0px 4px 16px 0px rgba(0,0,0,0.12)` | Dropdowns, popovers |
| Extra large | `--shadow-xl` | `0px 8px 24px 4px rgba(0,0,0,0.20)` | Modals, dialogs |

## Filter blur

`--blur-radius-*` feeds the CSS `filter: blur()` and `backdrop-filter` — the softening of an element or of whatever sits behind it. This is **distinct from `--shadow-blur-*`**, which is the blur *component of a `box-shadow`*; the two are not interchangeable.

<Callout type="info">
  **Shipped, but unconsumed today.** No component references `--blur-radius-*` (`grep -r "var(--blur-radius" components/` → 0). The family is available for frosted-glass / scrim treatments; until one ships, whether BDS keeps it is an open question for the naming ADR ([#1910](https://github.com/brikdesigns/brik-bds/issues/1910)).
</Callout>

| Token | CSS Variable | Value |
|---|---|---|
| Small | `--blur-radius-sm` | 8px |
| Medium | `--blur-radius-md` | 12px |
| Large | `--blur-radius-lg` | 14px |
| Extra large | `--blur-radius-xl` | 16px |

```css
.frosted-panel {
  backdrop-filter: blur(var(--blur-radius-md));
}
```
