<Callout type="warn">
  **BreadcrumbSwitcher is deprecated.** The switcher folded into [`Breadcrumb`](/docs/components/breadcrumb#switcher) as optional `options` / `switchLabel` / `onNavigate` props ([#2521](https://github.com/brikdesigns/brik-bds/issues/2521)). Use `<Breadcrumb options={…} switchLabel="…" onNavigate={…} />` — two or more options render the caret. The `BreadcrumbSwitcher` import is a thin shim with identical props, kept working until removal in a future major version.
</Callout>

## Migration

```tsx
// Before
<BreadcrumbSwitcher items={items} options={options} switchLabel="Switch service" />

// After
<Breadcrumb items={items} options={options} switchLabel="Switch service" />
```

The props are unchanged — `items`, `options`, `switchLabel`, `separator`, `linkComponent`, and `onNavigate` all move onto `Breadcrumb` verbatim. See the [Breadcrumb switcher section](/docs/components/breadcrumb#switcher) for the full API.
