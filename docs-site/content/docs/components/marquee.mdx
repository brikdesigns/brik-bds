Marquee renders an item set on a continuously scrolling track — the "trusted by" logo band pattern. It duplicates the item set once internally (the duplicate is `aria-hidden`) so the loop reads as one unbroken pass, then animates `translateX(0 → -50%)` at a fixed, linear speed.

It has one visual appearance — `direction`, `pauseOnHover`, and `fade` are behavior knobs, not distinct variants.

## Use it for

- A "trusted by" / partner-logo band on a marketing page
- Any horizontally-scrolling strip of same-sized items (badges, wordmarks) that should read as continuous, not paginated

Reach for a static [Cluster](/docs/components/cluster) layout when the item set doesn't need to scroll — Marquee's animation is the point, not a fallback for overflow.

## Accessibility

- The animation stops under `prefers-reduced-motion: reduce`. The track collapses to a single, centered, wrapped row instead of omitting motion handling.
- The duplicate item copy that fills the scrolling track is `aria-hidden="true"` — assistive tech announces the item set once, not twice.
- Marquee provides no accessible name of its own; wrap it with a heading (`<h2>Trusted by</h2>`) in the surrounding page, same as any other content band.

## API

{/* props-check: MarqueeProps @ components/ui/Marquee/Marquee.tsx */}

| Prop | Type | Default |
|---|---|---|
| `children` | `ReactNode` | — (required — the item set, rendered twice internally) |
| `direction` | `'ltr' \| 'rtl'` | `'ltr'` |
| `pauseOnHover` | `boolean` | `false` |
| `fade` | `boolean` | `true` |
| `gap` | `number \| string` | — (falls back to `--bds-marquee-gap`, 40px) |
| `logoHeight` | `number \| string` | — (falls back to `--bds-marquee-logo-height`, 24px) |

Inherits all native `<div>` attributes (`className`, `style`, `data-*`, …).
