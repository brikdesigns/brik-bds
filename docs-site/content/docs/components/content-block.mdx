ContentBlock is a fixed-slot Block-layer unit for named content with a known shape: `title` / `subtitle` / `description` / `actions`, each independently omittable. It owns the vertical rhythm BETWEEN its own slots — a tight gap ties `title` to `subtitle`, a medium gap separates the last text slot from `description`, and the same medium gap leads into `actions`. See [ADR-023](https://github.com/brikdesigns/brik-bds/blob/main/docs/adrs/ADR-023-content-blocks-and-prose-rhythm.md).

ContentBlock never owns layout. Column count and orientation come from a Layout primitive ([Stack](/docs/components/stack), [Grid](/docs/components/grid)) or a Container ([Card](/docs/components/card)) wrapped around it.

## Use it for

- A card's text content — feature copy, testimonial framing, pricing tile copy
- A CTA's heading, supporting line, and button
- Any named content unit with a known title/subtitle/description/actions shape

For open-ended, already-sanitized rich text with no fixed slot shape, use [Prose](/docs/components/prose) instead.

## Import

```tsx
import { ContentBlock } from '@brikdesigns/bds';
```

## Variants

### All slots

```tsx
<ContentBlock
  title="Membership Plans"
  subtitle="Choose the plan that fits your practice"
  description="Every plan includes unlimited support and quarterly reviews."
  actions={<Button variant="primary">View Plans</Button>}
/>
```

### Omitted slots

Any slot can be dropped independently — the rhythm collapses to whatever slots remain, with no leftover spacing from an omitted one.

```tsx
<ContentBlock
  title="First Impressions"
  description="75% of website credibility comes from design."
/>
```

### Title element level

`title` renders as `titleAs` (default `h3` — the common case nests inside a `Card`). Pick the element by outline position, not by convenience.

```tsx
// Direct outline sibling of the page's <h1>
<ContentBlock titleAs="h2" title="Membership Plans" />

// Decorative unit repeated in a grid — not an outline node
<ContentBlock titleAs="div" title="Feature name" />
```

<Callout type="info">
  See [HTML Semantics — Heading element selection](/docs/build-standards/html-semantics#heading-element-selection) for the full rule.
</Callout>

## Props

| Prop | Type | Default |
| --- | --- | --- |
| `title` | `ReactNode` | — |
| `subtitle` | `ReactNode` | — |
| `description` | `ReactNode` | — |
| `actions` | `ReactNode` | — |
| `titleAs` | `'h1' \| 'h2' \| 'h3' \| 'h4' \| 'div' \| 'p'` | `'h3'` |
