CellLink is the link inside a table or sheet cell that names the row. Neutral text at rest, brand on hover — color is the only affordance, never an underline — so a column of names reads as identifiers, not calls-to-action.

## Use it for

- The name cell of a table row (company, contact, agreement)
- A row that opens a sheet or runs a callback instead of navigating

For a real call-to-action, use [TextLink](/docs/components/text-link).

## Import

```tsx
import { CellLink } from '@brikdesigns/bds';
```

## Variants

### Link

Pass `href` to navigate. Renders an `<a>`.

<ComponentPreview code={`<BDS.CellLink href="#">Acme Corporation</BDS.CellLink>`}>
  <BDS.CellLink href="#">Acme Corporation</BDS.CellLink>
</ComponentPreview>

### Button

Omit `href` and pass `onClick`. Renders a `<button type="button">`.

```tsx
<CellLink onClick={() => openSheet(row.id)}>Acme Corporation</CellLink>
```

### Link that opens a sheet

Add `onActivate` to the anchor form to keep a real route but open a sheet over the list on a plain left-click. `href` stays rendered; Cmd/Ctrl/Shift/Alt-click and middle-click skip `onActivate` and open the route in a new tab.

```tsx
<CellLink href={`/companies/${row.id}`} onActivate={() => openSheet(row.id)}>
  Acme Corporation
</CellLink>
```

## Sizing

CellLink inherits the cell's font size and weight, so a linked cell and a plain-text cell in one column always match. There is no `size` or `weight` prop; set them on the cell.

## When *not* to use

<Callout type="warn">
  **Don't use CellLink for a call-to-action.** A review link or an action in a cell is a TextLink or Button. CellLink is only for the cell that names the row.
</Callout>

## Accessibility

- Renders a real `<a>` or `<button>`. Keyboard, focus ring, and context menu come from the platform.
- The accessible name is the visible text — use the row's name, not "View".
