Token Formula Reassessment — 2026-11-18

Updated 2026-11-19: primitive-colour rebuild, elevation refactor and the sync PR (section 2b).

Agents drift because the system teaches four contradicting things, not because the formula is hard.

  1. Three name rules in the pipeline. Most collections derive the CSS name from the Figma path. Some prepend the collection name in code. One drops it. One (elevation) is hardcoded. An agent can't predict a name from Figma alone.
  2. The wrong authority is injected every turn. brik-llm/operations/hooks/critical-rules.sh:134 says "tokens (dist/tokens.css only)". Brik-bds CLAUDE.md:17 says the opposite: the Figma-generated files are the authority, never dist.
  3. Pre-#2670 bare names are still taught. Docs, skills and the edit hook show --surface-primary instead of --bds-surface-primary. The hook regex only checks bare names, so an invented --bds-* name passes.
  4. An agent was allowed to mint a purpose. docs/adrs/ADR-050-data-visualization-layer.md:41 ("AGENT DECIDED: chart is a new colour purpose") added chart to tokens/naming-grammar.json:65,82,94. The lint reads that file, so nothing failed.

1. The one formula

OPERATOR CHOSE 2026-11-18: "Which single rule should every collection follow?" → Path = name.

--bds-{figma variable path, "/" → "-"}
RuleMeaning
The path is the nameFigma content-width/xl → --bds-content-width-xl. No exceptions in code.
A collection never adds a segmentA collection is a folder of modes. Its name is not part of the token.
A mode never adds a segmentLight/dark, compact/spacious and similar are mode values. Never -on-dark, -dark or -compact in a name.
Colour Semantic = {purpose}/{role}[/{state}]Purpose is the CSS layer being painted: page, surface, background, text, border. Exactly five.
A domain is a role group, never a purposebackground/chart/categorical-1 paints a fill. border/chart/categorical-1 paints a stroke. The purpose says which layer.
Non-colour = {scale}/{step}gap/md, ease/out, border-width/sm.
Names are born in FigmaAuthority is the generated files: tokens/figma-tokens*.css, modes-*.css, layout-fluid.css. Never dist/tokens.css, which also bundles hand-written names.
Agents never mint a name, purpose or scaleAn agent can propose a value. A missing name goes to the operator as a gap. No "AGENT DECIDED" on a name.
