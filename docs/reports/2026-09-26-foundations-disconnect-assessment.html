Verdict. Figma and the docs site agree with each other. The repo is the surface that moved: on 2026-08-31 commit 20c5d83f (#2229) hand-renamed 13 Foundations variables in the repo mirror (tiny→2xs, huge→2xl, heading/xxl→2xl, icon/tiny→3xs…), deferred the Figma write to #2227, and #2227 is still open 26 days later. The docs page and tokens/index.ts were never updated, so they still match Figma by accident, not by process.

Root cause (systemic, not one ticket): the pipeline is documented as Figma → sync → repo (foundation/index.mdx:12,122) but operated as hand-edit the repo mirror, defer Figma. Four of the last five foundations.json commits are hand edits; the last true reconcile against Figma was 0091e519 on 2026-08-13 (44 days). No gate reads Figma — every "Figma alignment" lint reads the repo's own mirror — so drift is undetectable by CI at Brik's Figma plan tier.
