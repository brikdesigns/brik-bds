2026-10-27 · Opus reassessment before building brik-bds#2601 · repo read on origin/main 4e656e25 · Figma read live from ❖ Brik Foundations (Rkdc3SIWJUdgoAkeadgZZe) via use_figma, after the operator's border-width update

Verdict: yes, this is a systemic class, not a one-off. Confidence: high.

One class: canon was copied out of its owning repo, kept its "source of truth" label, and no gate compares the copy to Figma.

Four mechanisms let it survive. Each is cited below.

  1. The March spec in brik-llm still calls itself the source of truth. Two MCP servers and a script read it. No drift check covers its folder.
  2. Border-width was hand-wired before the mode generator existed, and was never moved into it. The coverage gate exempts it and checks only that a selector exists.
  3. No single table says which repo owns which kind of file. So nothing flags a design-system file living in brik-llm.
  4. The repo's copy of Figma is stale, and nothing says so. design-tokens/foundations.json was last pulled 2026-10-13 (a46ba24d). Figma now has a new border-width scale and an icon collection that the copy lacks. Every gate reads the copy, so every gate is green against old Figma.

Brand themes can already override border-width values and modes (§3b, run this session). The override logic is sound; its inputs are stale.

What this means for #2601:

  • The pull and generator must keep both brand-kit paths working. The positive control above becomes a test.
  • No brand kit sets border-width today. brik.json is the only kit; a search for border-width in design-tokens/brand-kits/ came back empty (control: border matched 4 lines). So no kit breaks on the rename.
  • A kit that later aliases a border-width primitive by step must use the new numbering (new 100 = 1px; old 100 = 2px). The pull PR should state this in the token docs.
  • The portal says borderWidth has "no stored producer yet" (decision-set.ts:176-192) and its test pins bold (__tests__/decision-set.test.ts:231). Both move to thick.

Who uses it: no consumer source sets data-mode-borderwidth. Searches came back empty in brikdesigns and all 9 web/* sites; the control search for data-theme found tncld.
