# Checkbox

<ComponentLinks slug="checkbox" />

Themed checkbox for boolean selections. The label wraps the input so clicking the label toggles the checkbox. Supports controlled (`checked` + `onChange`) and uncontrolled (`defaultChecked`) modes. For multi-option selection with a legend and select-all, use [`CheckboxGroup`](/?path=/docs/components-checkbox-group--docs).

## Variants

Boolean state (`checked`, `disabled`, `indeterminate`) is exposed via Controls on the `Single` canvas above. Checkbox has no variant axis of its own — the multi-option group (legend, orientation, select-all/indeterminate parent) is [`CheckboxGroup`](/?path=/docs/components-checkbox-group--docs).

## Notes

> **Note** — For task / item completion state (circular, distinct from form selection), use [`CompletionToggle`](/?path=/docs/components-completion-toggle--docs). Checkbox is rectangular and intended for form-style binary choices (terms, preferences, opt-ins).

> **Note** — For any multi-option selection, use [`CheckboxGroup`](/?path=/docs/components-checkbox-group--docs) (#2120) — it owns the `<fieldset>`/`<legend>` grouping, the selected-values array, orientation, and the select-all/indeterminate parent. Reach for a bare `Checkbox` only for a single binary choice.
