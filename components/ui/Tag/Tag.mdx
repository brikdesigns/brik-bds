## Variants

**Appearance** (shared axis with Badge and Avatar — see [Vocabulary › Axes](https://design.brikdesigns.com/docs/primitives/naming-conventions)), **color**, and icon slots are exposed via Controls on Default:

- **`solid`** (default) — Saturated `--bds-background-*` fill with an on-color label: neutral is charcoal with a white label; each accent hue takes the dark ink `--bds-text-on-color-light`. A Tag is a small element placed on a surface, so its fill is a background token.
- **`subtle`** — Pale `--bds-background-*-light` fill with the dark-ink label `--bds-text-on-color-light` on every color.
- **`outline`** — Transparent fill, `--bds-text-primary` label, and a border only (`--bds-border-secondary` for neutral, `--bds-border-accent-{hue}` for a hue). Lower visual weight when Tags sit on a colored surface. The label carries the meaning, so the border is decorative and is not held to WCAG 1.4.11's 3:1.

**Color** is `neutral` (default) or an accent hue — `blue`, `green`, `orange`, `purple`, `yellow`, `red`, the same hues Avatar takes. **Boundary:** Tags carry classification, never status. There is no positive / warning / negative color on a Tag; for semantic status use `Badge` and its `tone`.

**Breaking in 0.222.** The old `subtle` (transparent + border) is now `outline`, and the old `muted` (quiet neutral fill) is now `subtle`. `muted` is removed. Migrate with `scripts/codemod-tag-appearance.mjs`; run it once, never twice.

**Service color:** Tag has no service-color axis. A Brik service-line category, or any glyph that should sit on a service fill, is a `ServiceTag`, using its `icon` prop for a custom glyph (#2417).

### Truncation

An indicator is one line and never wider than its container. A label that does not fit ends in an ellipsis, the icon stays whole, and a plain-text label carries its full text as a native `title`. Cap the width where it matters by giving the indicator a `max-width` or placing it in a constrained cell; keep labels short anyway — truncation is the safety net, not the design.
