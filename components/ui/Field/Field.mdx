# Field

<ComponentLinks slug="field" />

Read-mode label + value pair for page sections and Sheet body rows. One API covers text, tags, URLs, bullet lists, and empty states.

The label's typography tier is **derived from the container**: page-tier (`--label-md`) by default, sheet-tier (`--label-sm`) inside a `Sheet` body. Omit the `tier` prop and a component reused in both places renders correctly in each.

## Variants

Field has no semantic-variant axis — all variation (label, value content, orientation, empty fallback) is exposed via Controls on the canvas above. See [ADR-010 §components without a variant axis](../../../docs/adrs/ADR-010-storybook-axes-of-information.md) for the framework.

- **`vertical`** — label above value (default). Full-width value content; use for sheet body rows.
- **`horizontal`** — label / value on one row. Use for compact stat rows ("Status · Active", "Scraped · 8").

## CSS Override API

| Variable | Default | Use |
| --- | --- | --- |
| `--bds-field-label-size` | `var(--label-md)` | Label type size. `.bds-sheet__body` sets `var(--label-sm)`, so a Field inside a Sheet is sheet-tier without the caller passing `tier`. Set it on any other container to make that container's fields a different tier. |

`tier` is the per-instance form of the same knob: it declares the property on the Field root, and a declaration on the element beats one inherited from a container. That is what makes `tier="standard"` a working escape hatch for a page-tier field inside a Sheet body. Flip `tier` in the Playground Controls above to see `compact` type.

## Notes

- **Pass `tier` only to pin against the container.** A component that renders in both a page and a Sheet body — the case this derivation exists for ([#1383](https://github.com/brikdesigns/brik-bds/issues/1383)) — has no correct value to hardcode, because the right tier is only knowable at render time.
- The sheet-tier rendering is captured by the `Containers/sheet` `ReadMode` story, whose `play` opens the sheet so the body lands in the visual baseline.
