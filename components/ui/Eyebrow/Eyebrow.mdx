# Eyebrow

<ComponentLinks slug="eyebrow" />

The short uppercase kicker that sits above a heading. Owns the label font family, label-tier size, semibold weight, letter-spacing, and the tight gap to the heading below it. It renders `p` or `span`, never a heading — an eyebrow is not an outline node. It is not a `Tag` or `Badge`: those are status/category pills; an eyebrow is a plain line of text.
