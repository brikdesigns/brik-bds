# BrikBlocks

<ComponentLinks slug="brik-blocks" />

Decorative square-motif primitive — the "brik" mark from the /about redesign. Renders a run of 24×24px squares with an 8px gap, each tinted `light` / `dark` / `poppy` in the order given via the `cells` array.
