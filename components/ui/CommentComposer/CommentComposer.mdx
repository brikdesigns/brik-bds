### With mentions

## Notes

> **Note** — `onSubmit` may return a Promise. The composer shows its own pending state until it settles, clears on resolve, and keeps the text on reject; report the failure through `error`.

> **Note** — The payload is `{ body, mentions }`. `mentions` holds the entries picked from the list that are still in `body`, so the caller never re-parses the text.
