# Breadcrumb switcher

<ComponentLinks slug="breadcrumb-switcher" />

Breadcrumb trail plus a caret that opens a menu of sibling records — jump between other services in the same line, or other projects on the same client, without navigating back to an index page.

> **Note** — Deprecated. Use `<Breadcrumb options={…} switchLabel="…" onNavigate={…} />` instead ([#2521](https://github.com/brikdesigns/brik-bds/issues/2521)) — the switcher folded into `Breadcrumb` as optional props. The `BreadcrumbSwitcher` export is a thin shim with identical props, unchanged until removal in a future major.
