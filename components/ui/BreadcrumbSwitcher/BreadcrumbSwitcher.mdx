# BreadcrumbSwitcher

<ComponentLinks slug="breadcrumb-switcher" />

A `Breadcrumb` trail plus a caret that opens a menu of sibling records — switch between other services in the same line, or other projects on the same client, without navigating back to an index page.

Pass `linkComponent` (e.g. `next/link`) so linked crumbs route client-side, and `onNavigate` so selecting a sibling option routes client-side too — BDS owns no router, so the default is a full-page navigation (`window.location.href`). See [framework guides → client-side routing](/docs/getting-started/framework-guides).

## Variants

### Single option

A single option means there is nothing to switch to — the caret is omitted entirely, and the trail renders as a plain `Breadcrumb`.

<Canvas of={Stories.SingleOption} />

### Chevron separator

`separator` is forwarded to the internal `Breadcrumb`, so a switcher trail can
match the chevron breadcrumbs elsewhere on the same page. `Breadcrumb` owns the
`slash` default.

## Notes

> **Note** — The trailing crumb keeps `aria-current="page"` unchanged; the caret is a separate `aria-haspopup="menu"` control alongside the trail, never folded into the current crumb.
