# Marquee

<ComponentLinks slug="marquee" />

Seamless, accessible scrolling item ticker for logo bands and trust strips. Duplicates the item set once internally (the duplicate is `aria-hidden`) and animates a continuous `translateX` loop.

## Default

<Canvas of={Stories.Default} />

## Variants

`pauseOnHover`, `fade`, `gap`, and `logoHeight` are Controls on Default. `direction` is a listed axis — the side-by-side comparison reads better than toggling a Control:

## CSS Override API

| Variable | Default | Set by |
|---|---|---|
| `--bds-marquee-gap` | `var(--size-1000)` (40px) | `gap` prop |
| `--bds-marquee-logo-height` | `var(--size-600)` (24px) | `logoHeight` prop |

```tsx
<Marquee gap={32} logoHeight={32}>…</Marquee>
```

## Notes

> **Note** — Marquee does not apply a runtime `grayscale()` filter. Pre-monochrome logo SVGs before passing them in, and set real `alt` text + `loading="lazy"` on each `<img>` yourself.
