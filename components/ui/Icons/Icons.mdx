# Icon catalog

<ComponentLinks slug="icons" />

A browsable **catalog** of the BDS icon vocabulary, not a component — this page exports nothing (`components/ui/Icons/index.ts` is `export {}`). Every grid below is *derived* from the exports of `components/icons.ts` and rendered through the [`Icon`](/docs/components/icons) atom, so it shows the default `outline-bold` weight a consumer actually gets and cannot drift out of date (#2628).

**Which import you reach for depends on where you are.** The flat name constants are internal to BDS source — `components/index.ts` re-exports only the semantic `ACTION_ICONS` set, deliberately ([#1127](https://github.com/brikdesigns/brik-bds/issues/1127)). Inside this repo, `import { House } from '../../icons'`; from a consuming app, pass the `ph:*` string to `<Icon>` or import `ACTION_ICONS` from `@brikdesigns/bds`. There is no `@brikdesigns/bds/icons` subpath.

Each card names the constant, the `ph:*` string behind it, and whether the glyph resolves **offline** — present in the bundled subset (`npm run gen:icons`) at the weight the atom paints — or falls through to a runtime Iconify **CDN** fetch.

Icons are sized by `fontSize` (they inherit `currentColor` and the text cursor), so an icon beside text matches that text without a hard-coded pixel value.

## Patterns

### Fixed-width column alignment

Pass an explicit `width` (not `fontSize`) when icons head a vertical list: a fixed box keeps the labels on one optical column even though the glyphs differ in natural width. `flexShrink: 0` stops a long label from squeezing the icon.
