# Icons

<ComponentLinks slug="icons" />

The BDS icon set — Phosphor glyphs re-exported from `components/icons` and rendered with Iconify's `<Icon>`. Import the name, not the string: `import { House } from '@brikdesigns/bds/icons'` gives you a tree-shakeable reference the bundler can drop when unused.

Icons are sized by `fontSize` (they inherit `currentColor` and the text cursor), so an icon beside text matches that text without a hard-coded pixel value.

## Patterns

### Fixed-width column alignment

Pass an explicit `width` (not `fontSize`) when icons head a vertical list: a fixed box keeps the labels on one optical column even though the glyphs differ in natural width. `flexShrink: 0` stops a long label from squeezing the icon.
