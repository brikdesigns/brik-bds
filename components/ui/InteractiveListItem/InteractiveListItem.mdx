# InteractiveListItem

<ComponentLinks slug="interactive-list-item" />

Clickable horizontal row composed of leading + (title + subtitle) + trailing slots — the whole row is a single `<button>` click target with native focus ring, `Space` / `Enter` activation, and `disabled` support. Use it when a list row drills into something, such as opening a profile or a related task.

## Default

<Canvas of={Stories.Default} />

Slot presence (`leading` / `subtitle` / `trailing`), `size`, and `disabled` are all Controls on this story — toggle them in the Controls panel rather than reaching for a dedicated story.

## Patterns

### Activity feed

The `subtitle` slot accepts a `ReactNode`, so a row can carry multi-line metadata — a text line above a row of inline `<Badge>`s — with a caret in the trailing slot. This activity-feed composition is the irreducible case Controls can't express.

<Canvas of={Stories.ActivityFeed} />

### Selectable

Pass `selected` to turn the row into a toggle: a brand tint plus an inset brand ring, with `aria-pressed` reflecting the state. Use it for picker options and multi-select lists — a leading icon that swaps to a filled check pairs well with it. The ring is drawn with `box-shadow`, not `border`, so toggling a row never shifts its neighbours. Leave `selected` `undefined` for a plain drill-in row (no `aria-pressed`).

<Canvas of={Stories.Selectable} />

For a vertical image-first selectable (a photo grid, an avatar picker), reach for `SelectableMediaTile` instead — same selected semantics, media-tile shape.

## Read-only

Pass `interactive={false}` for a **display-only row** — a status list, a per-page composition list, any row that shows data without drilling in. It renders a non-interactive `<div>` with the same leading / title / subtitle / trailing slots, and drops every interactive affordance: no click target, no hover, no active scale, no focus ring. The button-only props (`onClick`, `disabled`, `selected`) are ignored.

**When to use which.** Default (`interactive`) when clicking the row *does* something — drills into a profile, opens a task, switches a persona. `interactive={false}` when the row is purely informational and the state lives in the trailing slot (a `Badge`, a `Tag`). If a read-only row grows a click target later, drop `interactive={false}` rather than wrapping it.
