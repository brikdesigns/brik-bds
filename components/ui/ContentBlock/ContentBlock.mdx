# ContentBlock

<ComponentLinks slug="content-block" />

Fixed-slot Block-layer unit — `title` / `subtitle` / `description` / `actions`, each independently omittable. Owns the vertical rhythm BETWEEN its own slots (ADR-023): a tight gap ties `title` to `subtitle`, a medium gap separates the last text slot from `description`, and the same medium gap leads into `actions`. It never owns layout — column count and orientation come from a Layout primitive (`Stack`, `Grid`) or a Container (`Card`) wrapped around it.

## Default

<Canvas of={Stories.Default} />

All four slots filled — the full shape. `title` renders as `titleAs` (default `h3`); pick the element by outline position, not by convenience — see [HTML Semantics](/docs/build-standards/html-semantics#heading-element-selection).

### Sizes

`size` scales `title` only — each step maps to the `--heading-{size}` token of the same name, while `subtitle`/`description` stay body-md at every step. Default `sm`. It's a Control on any story above; the gallery below shows all six side by side.

`xl`/`2xl`/`3xl` cover the display end of the ramp so a page-region title does not need a consumer-side override of `.bds-content-block__title` — reaching past the public API dies silently on any refactor, since an unmatched selector is not an error (brikdesigns#1512, brik-bds#2528).

## Patterns

Any slot can be omitted independently. Dropping `subtitle` collapses `title` straight to the medium `description` gap, with no leftover tight spacing.

### On a filled brand band

`onColor` swaps `title`/`subtitle`/`description` to `--text-on-color-dark` for a block sitting on a filled brand or dark surface. The block owns this — never push a per-instance `color` from the consumer into a slot the block renders. `--text-on-color-dark` is mode-invariant white, so one prop covers light and dark.

<Canvas of={Stories.OnColor} />

White on `--surface-brand-primary` is **3.78:1 — AA-large (3:1), not AA (4.5:1)**. Brand-primary fills are gated AA-large by policy (`tokens/contrast-pairings.json`, BDS-22 / ADR-015). The `title` is large text and unaffected; keep a band `description` short rather than running body copy long on the fill. For a *centered, measure-capped* section intro on a band, reach for [SectionHeader](/docs/components/section-header), which forwards `onColor`.
