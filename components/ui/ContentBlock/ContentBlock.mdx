# ContentBlock

<ComponentLinks slug="content-block" />

Fixed-slot Block-layer unit — `title` / `subtitle` / `description` / `actions`, each independently omittable. Owns the vertical rhythm BETWEEN its own slots (ADR-023): a tight gap ties `title` to `subtitle`, a medium gap separates the last text slot from `description`, and the same medium gap leads into `actions`. It never owns layout — column count and orientation come from a Layout primitive (`Stack`, `Grid`) or a Container (`Card`) wrapped around it.

## Default

<Canvas of={Stories.Default} />

All four slots filled — the full shape. `title` renders as `titleAs` (default `h3`); pick the element by outline position, not by convenience — see [HTML Semantics](/docs/build-standards/html-semantics#heading-element-selection).

### Sizes

`size` scales `title` only (`--heading-sm/md/lg`) — `subtitle`/`description` stay body-md at every size. Default `sm`. It's a Control on any story above; the gallery below shows the three side by side.

## Patterns

Any slot can be omitted independently. Dropping `subtitle` collapses `title` straight to the medium `description` gap, with no leftover tight spacing.
