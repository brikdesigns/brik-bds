# Avatar

<ComponentLinks slug="avatar" />

User profile images with automatic fallback to initials. Supports multiple sizes and optional status indicators for presence states.

## Default

<Canvas of={Stories.Default} />

## Variants

Initials-only fallback vs photo-backed avatar — the two content-type starting points. Size, status, and color are Controls on both.

<Canvas of={Stories.Initials} />

`appearance` is the indicator axis shared with Badge and Tag: `solid` (default) is the saturated accent fill, `subtle` its pale `-light` step with a dark-ink label. With no `color`, `subtle` is the pale brand fill. No effect once an image loads.

- **`xs`** — 24px, dense inline affordances (dropdown triggers, compact rows)
- **`sm`** — 32px, compact lists and inline mentions
- **`md`** — 40px, default for cards and comments
- **`lg`** — 48px, profile headers and featured users
- **`xl`** — 64px, hero profiles and account settings
