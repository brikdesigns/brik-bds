# Segmented control

<ComponentLinks slug="segmented-control" />

Pill-shaped toggle for switching between mutually exclusive views or modes. Unlike `TabBar` (which switches between sibling panels of one entity, such as its lifecycle status or the sections of a settings page), `SegmentedControl` changes only how the same data is shown — a view mode like list or grid — in place. It never selects a data segment; see [page chrome placement](https://design.brikdesigns.com/docs/build-standards/composition-layers#page-chrome-placement).

## Variants

- **`sm`** — Compact toolbars, dense UI
- **`md`** — Default for forms and panels
- **`lg`** — Prominent page-level toggles
