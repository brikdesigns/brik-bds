# Text link

<ComponentLinks slug="text-link" />

Themed inline anchor link styled to match BDS body typography. Color transitions to brand on hover. Two sizes (`default`, `small`); an `emphasis` axis (`brand`, `neutral`); an underline-visibility axis (`hover`, `always`, `none`); accepts standard `<a>` attributes (`href`, `target`, `rel`) and optional leading / trailing icon slots.

## Variants

TextLink has no semantic *style* variant axis — size, emphasis, and underline-visibility are all exposed as Controls on Default (#2144). External-link behavior is set via standard anchor Controls (`target`, `rel`), not a separate story. See [ADR-010 §components without a variant axis](../../../docs/adrs/ADR-010-storybook-axes-of-information.md) for the framework.

<Canvas of={Stories.Default} />

- **`default`** — body-md (16px)
- **`small`** — body-sm (14px), for footnotes / captions

### Emphasis

<Canvas of={Stories.Default} />

- **`brand`** (default) — brand link color at rest. Use for a **page-level link or CTA** that should stand out from body copy.
- **`neutral`** — `--text-primary` at rest. Use for a **lower-emphasis identifier link** — a name cell in a table, where a column of links should read as a column of identifiers, not calls-to-action. Both values transition to `--text-brand-primary` on hover, so color still signals interactivity.

### Underline visibility

<Canvas of={Stories.Default} />

- **`hover`** (default) — no underline at rest, underline appears on hover. Use for a **standalone** link (nav item, card action, button-adjacent link) where the surrounding context already signals it's interactive.
- **`always`** — underline visible at rest and on hover. Use for a link **inline in a sentence of body text** — at body size, color alone isn't a sufficient cue to distinguish a link from surrounding text (WCAG 1.4.1 Use of Color). This is a backward-compatible addition: the default is unchanged `hover` behavior.
- **`none`** — no underline at rest **or** on hover, including the seamless icon/avatar underline. Use for a **color-only affordance** such as a table cell, where a leading Avatar / indicator must never be underlined. Only sound where the surrounding context already marks the link as interactive — never for a link inline in prose (WCAG 1.4.1).

When a link carries an `iconBefore` / `iconAfter`, the underline is drawn as **one seamless line** under the icon, the gap, and the text — the icon underlines with the words, not just the words alone. This is automatic for any icon-bearing TextLink under `hover` and `always`, and fully suppressed under `none`; no prop is required beyond the underline axis.

## Notes

> **Note** — For external links, set `target="_blank"` **and** `rel="noopener noreferrer"` together. The component doesn't add these automatically — the security pair is the consumer's responsibility. The Storybook Controls expose both for inline testing.

> **Note** — **No `disabled` state today.** TextLink is an `<a>` element; HTML `disabled` doesn't apply to anchors. The accessible pattern is `aria-disabled="true"` + remove `href` + muted styling — not currently implemented. Tracked separately; consumers needing a disabled link should render plain text (or a [`Button variant="ghost"`](/?path=/docs/components-button--docs)) instead.
