# ActivityTimeline

<ComponentLinks slug="activity-timeline" />

Vertical, chronological list of events — each row a leading icon node, label, optional detail, and timestamp, connected top-to-bottom. Pass the whole sequence as the `events` array; the first entry marks the origin.

## Default

The component renders whatever `events` sequence it's given — edit the `events` Control to see any shape (single origin event, a full task lifecycle, a resolved request flow).

<Canvas of={Stories.Default} />

## Content

An event's optional `content` slot takes any node and renders it below `detail`, above `timestamp` — a `TagGroup` of changed fields, or a decision body with a `Tag`, text, and a clickable `TextLink`. The consumer composes the nodes; ActivityTimeline stays a pure display component.

<Canvas of={Stories.WithContent} />

The category channel is the `icon` slot plus a `Tag` inside `content`. There is no per-category dot tint: category and status are orthogonal ([Indicators](/docs/build-standards/indicators) — "Category and status are orthogonal"), so a dot colour would conflate the two. Name the category with a `Tag`; name a status with a `Badge`.
