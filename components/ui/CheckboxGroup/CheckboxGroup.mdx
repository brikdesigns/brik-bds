# CheckboxGroup

<ComponentLinks slug="checkbox-group" />

Multi-select group of [`Checkbox`](/?path=/docs/components-checkbox--docs) options in a native `<fieldset>` + `<legend>`. The wrapper owns the selected-values array and orientation, and optionally renders a select-all parent that reflects `indeterminate` when the selection is partial. `Checkbox` stays the standalone item for a single binary choice. Pass `options` for plain checkboxes, or `children` to put group-aware items inside the same fieldset.

## Patterns

### Children mode

With `children`, the group provides its selected array, toggle handler, optional `name` and `disabled` to [`InteractiveListItem`](/?path=/docs/components-interactive-list-item--docs) and [`SelectableMediaTile`](/?path=/docs/components-selectable-media-tile--docs) through one shared hook (`useSelectionGroup`, internal). Each item then renders a `<label>` around a visually hidden native checkbox instead of an `aria-pressed` button. Give each item a `value`. See the live pick-many list on [`InteractiveListItem`](/?path=/docs/components-interactive-list-item--docs#pick-many) (ADR-045). Select-all is an `options`-mode feature; it is not rendered with `children`.

## Notes

> **Note** — Grouping is a native `<fieldset>` + `<legend>`; the legend names the group for assistive tech. The select-all parent uses the checkbox `indeterminate` DOM property (a "some, not all" dash) — set it via the `selectAllLabel` prop, never by hand.

> **Note** — Supersedes the former "no CheckboxGroup wrapper" guidance on [`Checkbox`](/?path=/docs/components-checkbox--docs). Use CheckboxGroup for any multi-option selection; reach for a bare `Checkbox` only for a single binary choice.

> **Note** — For single-select (choose one), use [`RadioGroup`](/?path=/docs/components-radio-group--docs). For task/item completion state, use [`ChecklistGroup`](/?path=/docs/components-checklist-group--docs).
