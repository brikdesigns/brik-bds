## CSS Override API

Component-scoped CSS variables declared on `.bds-texture`. Override them with a rule that targets the element (or its `style` prop) — a value set on a wrapping element is replaced by the element's own declaration.

| Variable | Default | Controls |
|---|---|---|
| `--bds-texture-spacing` | `15px` | Grid pitch — distance between dots or lines |
| `--bds-texture-mark-size` | `1px` | Dot diameter / line thickness |
| `--bds-texture-opacity` | `0.3` | Layer opacity |
| `--bds-texture-fade` | `radial-gradient(ellipse at center, black 50%, transparent 100%)` | `mask-image` applied when `fade` is set |

The mark color is not a hook — it reads `--bds-border-secondary`, which already flips per theme.

```css
/* Example: a denser grid in a hero section */
.hero .bds-texture {
  --bds-texture-spacing: var(--bds-space-300);
}
```

**Renamed from `BackgroundPattern`.** The `--bds-bg-pattern-size`, `-dot-size`, `-opacity`, `-fade` and `-color` names are still read as fallbacks for one minor, then removed. Move to the names above. The `.bds-background-pattern` class is still emitted beside `.bds-texture` for the same period; select on `.bds-texture`.
