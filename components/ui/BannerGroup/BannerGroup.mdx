# BannerGroup

<ComponentLinks slug="banner-group" />

Vertical stack of `<Banner>` elements with locked spacing. Replaces the per-banner `marginBottom` and the ad-hoc `<Stack>` wrapper consumers reach for when a page needs more than one banner.

The group owns the space **between** banners only. The space below the group belongs to the parent layout's `gap`, same as any other block.

Order is the author's responsibility, not the component's — sort children `negative → warning → info → positive → announcement`, global before contextual within a tone. The full rule, page placement, and the cases where a second banner is the wrong answer live in the [banner-groups build standard](https://design.brikdesigns.com/docs/build-standards/banner-groups).

### Gaps
