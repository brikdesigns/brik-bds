# Badge

<ComponentLinks slug="badge" />

Status indicators and labels for displaying contextual information. Badges use semantic system colors to communicate status at a glance, with `solid` (saturated bg) and `subtle` (pastel bg) appearance values.

## Default

<Canvas of={Stories.Default} />

## Variants

The semantic axis is **status** — six tones an agent picks as a starting template. `info` is the canonical tone shown in **Default** above; the other five each get a story below. `appearance`, `size`, and `density` are Controls on any story; the size gallery below shows the size axis side-by-side.

### Neutral

A muted-gray, low-emphasis tone for inert states — skipped steps, not-started items, unlinked records. Uses the pure grayscale ramp, so it reads a step below `info` (which carries the informational system-neutral tone).
